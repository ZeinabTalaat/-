# ⚡ Power Plants Performance Dashboard

## 📊 Overview
This project presents an interactive dashboard for analyzing the performance and safety status of different power plant systems.  
It focuses on monitoring operational conditions and comparing key systems such as Fire, Deluge, and Foam systems.

---

## 🎯 Objective
The main goal of this dashboard is to:
- Monitor the safety status of power plant systems
- Identify systems with issues or maintenance needs
- Compare performance across different systems
- Support data-driven decision making in plant operations

---

## 📌 Key Features
- 📈 Visualization of system status (Good / Issues / Under Maintenance)
- ⚙️ Comparison between different plant systems
- 🔍 Filtering options for deeper analysis
- 🧾 Overview of inspection and safety data
